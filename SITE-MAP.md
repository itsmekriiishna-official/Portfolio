# Website Structure

The canonical route tree lives in `Web Pages/`:

- `/` Home entry point
- `/Web Pages/` Website tree map
  - `/Web Pages/home/` Home section
    - `/Web Pages/home/experiments/` Experiments
  - `/Web Pages/about/` About
  - `/Web Pages/work/` Work
  - `/Web Pages/tools/` Tools
    - `/Web Pages/tools/design/` Design Tools
  - `/Web Pages/cursors/` Cursors
    - `/Web Pages/cursors/collections/` Cursor Collections
  - `/Web Pages/resources/` Resources
  - `/Sunset/` Design Your Sunset (Realistic sunset gradient studio)

Root-level section folders are retained as compatibility routes for existing links.
